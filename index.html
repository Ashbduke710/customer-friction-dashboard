Decision

Methodology & project notes

What this prototype demonstrates

This project shows how I would structure ambiguous customer feedback, validate AI-assisted outputs and turn the analysis into a product decision. The interface is a working front-end prototype; all records and quotations are synthetic.

Data model

  • Feedback source, customer segment, theme, severity and confidence
  • Frequency and reach estimates by problem area
  • Customer-impact and implementation-confidence inputs
  • Traceable example evidence and a recommended next action

Human-in-the-loop controls

  • Review every record below 80% classification confidence
  • Review all severity-5 records regardless of model confidence
  • Compare a stratified human-coded sample with model labels
  • Document overrides and revise the taxonomy when disagreement clusters

Opportunity score

Score = 0.30 × volume + 0.30 × severity + 0.25 × customer impact + 0.15 × confidence

Each input is normalized to a 100-point scale. The score is a prioritization aid—not a substitute for discovery, technical feasibility review or product judgment.

Transferable experience

My healthcare operations background required the same core habits: finding patterns across high-volume interactions, resolving workflow friction, documenting accurately, using Epic and Excel, and explaining complex processes clearly to different users.
